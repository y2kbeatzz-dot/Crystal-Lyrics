New to browser extensions? Here's the quick setup ↗
  1. Download and extract the ZIP to a folder you'll keep.
  2. In desktop Chrome, go to chrome://extensions (or edge://extensions in Edge).
  3. Enable Developer mode, choose Load unpacked, and select the extracted CrystalLyrics folder containing manifest.json.
  4. Refresh YouTube or YouTube Music. You're ready.

CrystalLyrics is not listed in the Chrome Web Store; this is a manual install.

GOOD TO KNOW

A few little details.

How do I get started?

Download the ZIP and extract it, then open your browser's Extensions page. Turn on Developer mode, select Load unpacked, and choose the CrystalLyrics folder containing manifest.json. A short step-by-step guide is just above.

Is CrystalLyrics actually free?+

Yes. The extension is MIT-licensed and has no subscription, account, telemetry, or API key requirement.

Does it work with Spotify or Apple Music?+

The current 1.4 extension works on desktop YouTube and YouTube Music only. It does not integrate with Spotify or Apple Music streaming. Artwork color lookup may use Apple's public iTunes Search API.

Will every song be perfectly word-synced?+

Not always. Supplied word timestamps are preferred. If only line timestamps exist, CrystalLyrics estimates the position of each word and labels it as estimated. You can also import timed lyrics or opt into local audio timing; singing recognition isn't perfect.

Do I need to install anything else?+

No build tools or server are required. You just extract the extension folder and use Chrome or Edge's Load unpacked option. Optional local audio analysis may download a sizable model on first use.

Is audio sent to a server?+

Optional audio timing captures the browser tab only when you start it, processes the recording locally, and discards the audio afterward. Lyric lookups send song metadata to LRCLIB; artwork search can query Apple's service. See the extension README for details.

Can I turn down the animations?+

Yes. The extension has independent visual effect toggles and a Reduce motion setting, which is enabled by default. This site also respects your device's reduced-motion preference.
